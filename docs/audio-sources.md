# 游戏声音说明

当前生效的四段声音均由项目内的合成工具生成，不依赖外部音频素材。

| 游戏用途 | 生效文件 | 声音设计 |
| --- | --- | --- |
| 投币 | `coin-real.wav` | 硬币滑入币道，带轻微金属碰撞和触点声 |
| 下爪按钮 | `drop-button-real.wav` | 塑料按钮按下、触点闭合并回弹 |
| 轨道移动 | `rail-loop.wav` | 平稳的电机与滑轨底声，可连续循环 |
| 成功进入出口 | `prize-chute.wav` | 娃娃落入出口后的柔软碰撞和轻微挡片声 |

生成入口：`npm run audio:generate`

核心合成参数位于 `tools/audio-synthesis.ts`，生成结果为 44.1kHz、16 位、单声道 WAV。机内娃娃掉落继续保持无声。

旧的四段 MP3 暂时保留但不再使用，待新音效试听确认后删除。
